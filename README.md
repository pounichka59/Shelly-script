# Scripts pour modules Shelly

J'ai réalisé cet exemple complet et fonctionnel de script adapté à l'utilisation de modules Shelly.  **je n'ai trouvé nulle part sur le Net le moindre exemple complet de script Shelly, ni ici sur GitHub ni ailleurs !**  *(ni le constructeur sur son site officiel).* en espérant que ce partage vous sera utile :-)

**avantage:** possibilité de programmer des interractions entre différents éléments (capteurs, luminaires, télécommandes ...), de personnaliser différents scénarios ... le tout sans nécessité de disposer d'un accès à internet.

exemple d'utilisation: une porte ou une fenetre ouverte juste à coté d'un radiateur: l'alimentation du radiateur se désactive automatiquement ....    autre exemple: un clic sur une telecommande bouton, sans wifi ni internet un ensemble d'éclairages s'éteint, ou s'allume, ou change d'intensité, de couleur en particulier... aujourd'hui ce type de comportement n'est généralement possible que sous la condition que le matériel soit connecté à internet ou à un serveur local, la solution est ici et unique: un module  Shelly utilisant un script...

---

## Un module Shelly, avec son script:

- Est capable de fonctionner sans Internet.  
- Est capable de fonctionner sans réseau (communication en bluetooth uniquement).  

Une télécommande bouton ou un capteur ne dépend plus d'internet ni du wifi pour fonctionner (intéressant dans un garage par exemple). 

Il est à noter que la mise en place et la gestion de scripts sur modules Shelly ne s'adresse pas à un utilisateur ordinaire, mais à un utilisateur de profil technique, initié et équipé (avec un minimum d'outils logiciels dont principalement un éditeur de texte brut, qui n'est pas du tout un logiciel de traitement de texte que vous utilisez pour la rédaction de vos courriers)...   pour une famille ordinaire cette solution n'est pas toujours idéale, mais si vous êtes ici sur GitHub alors vous saurez tirer parti et profiter pleinnement de ce partage...

## Avantages d’une gestion sans cloud

Contrairement à la totalité des produits concurrents, à la fois:

- Fonctionne sans accès Internet.  
- Interactions entre les modules, chacun autonome.
- compatibilité bluetooh + Wi-fi et parfois également raccord physique par cable ethernet (équipements référencés "pro")
